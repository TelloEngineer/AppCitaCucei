# Description

It’s a react native application, it was designed for android,
the objective is a UI app for create appointment to come
into cucei, you can decide gate and date when you want to
visit cucei, you just need to describe how you will look when
you came, so security could let you in.
react native combine html, css and javascript lenguage to
create movil apps. this is the client for Cucei_Citas. both are
for a project on school.

## Quick Start
you need node.js
first you need to install every dependency: 
  npm install
after that command, you can start the app:
  npm start
